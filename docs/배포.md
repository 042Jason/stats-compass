# 생애나침반 — Git · Vercel 배포

이 저장소는 **한 폴더에 둘**이 들어 있습니다.

```
보수교육_프로젝트/
├── src/seed/              시드 스크립트 (로컬에서만 실행. 배포 대상 아님)
├── data/seed/             시드 입력·중간 산출물
├── docs/                  문서·시연 목업
└── stats-compass-web/     ← Next.js 앱. Vercel 이 배포하는 건 여기뿐입니다
```

Vercel 설정에서 **Root Directory 를 `stats-compass-web` 으로** 잡아야 합니다.
루트로 두면 시드용 `package.json` 을 읽고 빌드에 실패합니다.

## 3. Vercel

### 3-1. 프로젝트 만들기

1. vercel.com → **Add New → Project** → 방금 만든 저장소 선택
2. **Root Directory** 를 `stats-compass-web` 으로 지정 ← 이걸 빠뜨리면 빌드 실패
3. Framework Preset 은 자동으로 **Next.js** 가 잡힙니다. 그대로 둡니다

### 3-2. 환경변수

Settings → Environment Variables 에 다섯 개를 넣습니다.
`.env.local` 은 커밋되지 않으므로 따라가지 않습니다. 여기서 다시 넣어야 합니다.

| 이름 | 값 | 노출 |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | `https://vfubxcarvrgoetxemroo.supabase.co` | 브라우저 |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | `sb_publishable_...` | 브라우저 |
| `NEXT_PUBLIC_SITE_URL` | 배포 후 받은 주소 (`https://....vercel.app`) | 브라우저 |
| `OPENAI_API_KEY` | `sk-...` | **서버만** |
| `KOSIS_API_KEY` | 44자 키 | **서버만** |

**`SUPABASE_SERVICE_ROLE_KEY` 는 넣지 마세요.** RLS 를 우회하는 키이고
웹앱은 쓰지 않습니다. 시드 스크립트(로컬)에서만 씁니다.

`NEXT_PUBLIC_` 접두사가 붙은 것은 브라우저 번들에 그대로 실립니다.
`OPENAI_API_KEY` 나 `KOSIS_API_KEY` 에 실수로 붙이면 키가 공개됩니다.

### 3-3. 배포 후 확인

`NEXT_PUBLIC_SITE_URL` 은 주소를 받은 뒤에 채우고 **재배포**해야 반영됩니다.

확인할 곳:

1. `/` — 목록이 뜨는가 (Supabase 연결)
2. `/research` — 질문을 넣으면 결과가 나오는가 (OpenAI 임베딩 + RPC)
3. `/research` 의 **수치로 보기** → 불러오기 (KOSIS API)
4. `/graph` — 온톨로지 탐색기

## 4. 알아 둘 것

### 검색은 매 요청마다 돕니다

`/research` 는 `dynamic = "force-dynamic"` 입니다. 캐시하지 않습니다.
질문마다 OpenAI 임베딩 1회 + Supabase RPC 1회가 나갑니다.
시연 중 같은 질문을 여러 번 눌러도 매번 비용이 발생합니다. 큰 액수는 아닙니다
(`text-embedding-3-small` 기준 질문 하나에 소수점 아래).

### KOSIS 호출 제한

분당 200건입니다. **수치로 보기**에서 통계표 12개를 부르면 표당 최대 2회
(메타 + 자료)라 24건입니다. 여러 명이 동시에 누르면 한도에 닿을 수 있습니다.
메타는 서버 메모리에 1시간 캐시되지만, Vercel 서버리스는 인스턴스가 갈리면
캐시도 갈립니다. 시연 직전에 한 번 눌러 캐시를 데워 두면 안전합니다.

### 시드 스크립트는 배포되지 않습니다

`src/seed/*` 는 Vercel 이 건드리지 않습니다. 데이터를 갱신하려면 로컬에서
돌리고, DB 가 바뀌면 배포된 앱에 자동 반영됩니다 — 같은 Supabase 를 보니까요.

### 마이그레이션 순서

새 환경에 DB 를 다시 만든다면 `stats-compass-web/supabase/` 의 SQL 을 번호순으로
실행합니다. 다만 `0011`~`0016` 은 같은 함수를 계속 다시 정의하는 것이라
**마지막 `0016_recency_fix.sql` 하나만 돌려도 됩니다.**

| 파일 | 성격 |
|---|---|
| `0004`~`0008` | 테이블·인덱스 (전부 필요) |
| `0009`~`0016` | `graphrag_search` 재정의 (**0016 하나면 충분**) |
| `0013_table_periods.sql` | 컬럼 추가 (필요) |
